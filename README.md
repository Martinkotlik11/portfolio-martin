Updated portfolio organized by subject relevance for nuclear-oriented applications. Includes 12 case-study pages, CV, images, and available original reports. Nuclear cogeneration is described as in progress without a PDF. The welding report supplied by the user was excluded because its named authors do not include Martín.

## Publish on GitHub Pages
Unzip. Upload ALL of the files and both `assets/` and `docs/` folders into the REPOSITORY ROOT. Replace prior versions of `index.html` and `style.css`. Remove obsolete files only if you want; they do not obstruct deployment. Settings → Pages → Deploy from main / (root).

**Important:** `index.html` must appear at the repository root and PDFs inside `docs/`. Verify report links after deployment.
